# 🥽 FlightXP_VR – Immersive Flight Simulator

English Version Below

FlightXP_VR è un simulatore di volo immersivo sviluppato in **Unity** e **C#**. Il progetto permette all'utente di vivere l'intera esperienza aeronautica, dalla fase di assemblaggio tecnico al volo operativo in diverse modalità.

### 🎮 Esperienza di Gioco
- **Customization:** Costruisci e personalizza il tuo velivolo prima del decollo.
- **Tutorial:** Missioni guidate per apprendere i comandi di volo in VR.
- **Free Flight:** Esplorazione libera degli scenari.
- **Target Practice:** Modalità sfida per testare la precisione di manovra e puntamento.

---

### 🖥️ UI & Interaction Design
Il focus del progetto è l'immersività, ottenuta attraverso un mix strategico di interfacce:

* **Interfacce Diegetiche (In-World):** Menu e indicatori integrati direttamente nell'ambiente di gioco e nel cockpit del velivolo. L'utente interagisce con gli strumenti come se fossero oggetti fisici reali.
* **Interfacce Non-Diegetiche:** Menu di sistema e HUD (Heads-Up Display) funzionali per la gestione delle impostazioni e dei parametri tecnici fuori dal contesto narrativo.

---

# 🥽 FlightXP_VR – Immersive Flight Simulator

FlightXP_VR is an immersive flight simulator developed using **Unity** and **C#**. The project allows users to experience the full aeronautical cycle, from technical assembly to operational flight across various modes.

### 🎮 Gameplay Experience
- **Customization:** Build and personalize your aircraft before takeoff.
- **Tutorial:** Guided missions to learn VR flight controls.
- **Free Flight:** Open exploration of the flight environments.
- **Target Practice:** Challenge mode to test maneuvering and aiming precision.

---

### 🖥️ UI & Interaction Design
The core of the project is immersion, achieved through a strategic mix of interfaces:

* **Diegetic UI (In-World):** Menus and indicators integrated directly into the game environment and the aircraft cockpit. The user interacts with instruments as if they were real physical objects.
* **Non-Diegetic UI:** System menus and functional HUDs (Heads-Up Display) for managing settings and technical parameters outside the narrative context.

---

### 🛠️ Tech Stack
- **Engine:** Unity
- **Language:** C#
- **VR Toolkit:** XR Interaction Toolkit / Oculus Integration.
- **License:** Apache License 2.0
